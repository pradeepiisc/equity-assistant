# Research notes

One markdown file per video / article. The tracker indexes every `*.md` here except this README
(you can also write notes from the dashboard's **Notes** page — it saves them here).

```markdown
---
title: Defence smallcaps with big order books
source: https://www.youtube.com/watch?v=...
channel: Channel name
date: 2026-10-11
---
$ROSSTECH add — order book ~3x revenue, aerospace plant by Q4. entry 650 target 1100 sl 560
$ZELIO watch: EV two-wheelers, wait for Q2 numbers
- APOLLOPIPE: reduce, guidance deferred again

Anything else is free text.
```

- **Mention** a stock with `$SYMBOL` anywhere in a line, or start a bullet with `- SYMBOL:`.
  NSE symbols and BSE scrip codes (e.g. `$543619`) both work.
- **Stance** = first of these words after the mention: `add` / `add more` / `buy` / `accumulate`,
  `reduce` / `trim` / `book profit`, `exit` / `sell`, `watch` / `idea` / `research`, `hold`, `avoid`.
  No word → `mention`.
- **Levels**: `entry 650` (or `buy below 650`), `target 1100` (or `tgt`), `sl 560` (or `stop`).
  You get an alert when the daily close crosses a level.
- Stocks you mention but don't hold or watch become **tracked ideas**: prices, DMAs, phase,
  filings and deals are followed for them, and they're listed under *Ideas from your notes*.
